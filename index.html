Alert Map

Map pins appear only when an alert arrives, using the alert coordinates entered in Settings. No GPS module or SoftAP is used. The MPU6050 temperature is its chip reading, not a calibrated ambient-temperature measurement. SpO2 is an experimental estimate and must not be used for medical decisions. MAX30102 detects finger contact/pulse at its sensor; it does not identify a person at a distance.

Remote SMS Command

ESP32 sends the coordinates entered in Settings and an OpenStreetMap link to the configured phone number. Send LOCATION by SMS from that same number to request them.

Device Settings

Settings are saved in this browser and sent to ESP32 over MQTT when connected. The ESP32 stores received thresholds and coordinates in flash. Coordinates are used only with alert messages and alert map pins; they do not create a normal location marker. MQTT credentials in a hosted HTML page are visible to visitors; restrict the broker account to the required topics.
